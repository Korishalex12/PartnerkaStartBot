# PartnerkaStartBot

Готовый шаблон Telegram-бота для продажи цифрового PDF.

Важно:
- Не публикуйте BOT_TOKEN.
- STAR_PRICE=700 — временное техническое значение, не утверждение, что это ровно 1490 ₽.
- Для цифровых товаров внутри Telegram используется Telegram Stars (XTR).
- Перед запуском замените TERMS_URL и SUPPORT_TEXT.
- Сначала тестируйте платежи, затем переходите в production.
